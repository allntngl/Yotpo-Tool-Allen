Authentication

Generate and manage the access token (U-Token) used by every API call.

Generate access token

POST/core/v3/stores/{store_id}/access_tokens

The token is sent as X-Yotpo-Token on every other call and kept only for this browser session. Your API secret is never saved.

Retrieve products

GET/core/v3/stores/{store_id}/products

Retrieve by Product ID

GET/products?external_ids=… · /products/{yotpo_product_id}

Create product

POST/core/v3/stores/{store_id}/products

Adds a product to the store's Yotpo catalog. The external ID must match the product ID on the store's platform.

Retrieve orders by Product ID

GET/core/v3/stores/{store_id}/ordersscan

The API has no product filter for orders, so this pages through orders and keeps those whose line items match the external product ID. Narrow the date range to scan faster.
