Privacy Policy

Yotpo Tool and the Yotpo Tool Connector extension

What the tool does

The Yotpo Tool is a support console for working with a store's data through the Yotpo APIs. The Yotpo Tool Connector is a browser extension that sends the tool's API requests to Yotpo, because browsers block the page from doing so directly.

Data handled

When you use the tool, it sends your requests to Yotpo, along with your Yotpo access token. These requests and Yotpo's responses can include store data such as product details, order details and customer names and emails.

How it's used

  • Data is only sent between the Yotpo Tool page and Yotpo's APIs (api.yotpo.com and api-cdn.yotpo.com), to carry out the action you request.
  • The extension doesn't store, log, sell or share any data, and doesn't send it anywhere else.
  • The tool page keeps your Store ID in your browser so you don't have to retype it, and keeps the access token only for the current browser tab session. Your API secret is never stored.
  • The extension only runs on the Yotpo Tool site and doesn't read or change any other website.
